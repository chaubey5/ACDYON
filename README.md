> **GAMEON** is a hyper-premium, high-performance landing page designed to rival AAA studio websites. It features seamless spring-physics animations, embedded cinematic auto-play trailers, and an aggressive neon esports aesthetic.

---

## 🌟 Elite Features

| Feature | Description |
| :--- | :--- |
| 🎥 **Cinematic Trailers** | Embedded YouTube iFrames with `mix-blend-screen` deliver permanent, block-proof HD background gameplay loops. |
| ⚡ **Framer Motion Integration** | Every UI element is rigged with spring-physics entry animations and aggressive interactive hover states. |
| 🛡️ **Anti-Block Architecture** | Utilizes direct Wikipedia Commons imagery to bypass strict corporate firewalls and ISP image-blocking. |
| 🏎️ **Cinematic Scrolling** | Global `scroll-behavior: smooth` combined with Next.js 15 routing creates seamless camera panning between sections. |
| 🎨 **Esports Aesthetic** | Designed with the `Oswald` font, neon pink-to-blue gradients, and dark mode optimizations (`#0b0b0f`). |

## 🚀 Quick Start

Want to boot up the portal locally?

```bash
# 1. Install Dependencies
npm install

# 2. Ignite the Dev Server
npm run dev
```

Target your browser to [http://localhost:3000](http://localhost:3000) and step into the arena.
